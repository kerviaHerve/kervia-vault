Coffre — réglages

L'extension accède au coffre via un token dédié : crée-le dans la webui (Paramètres → Extension Firefox), colle-le ci-dessous, puis déverrouille depuis l'icône.

Connexion

Crée-le dans la webui → Paramètres → Extension Firefox → « Créer le token », puis colle-le ici. Il ne donne accès qu'aux blobs chiffrés du coffre — sans le mot de passe maître, il ne révèle rien.

Une URL autre que vault.kervia.ch demandera une permission d'origine à l'enregistrement.

Sécurité

Verrouillage automatique après inactivité

Zero-knowledge : le mot de passe maître et la clé ne vivent qu'en mémoire, jamais sur disque.

Aucune interface n'est jamais injectée dans les pages web (ni icône dans les champs, ni bulle) : le remplissage n'agit que sur ton action dans le popup ou via Ctrl+Shift+L.

Le coffre déchiffré reste dans le processus d'arrière-plan ; verrouillage auto après inactivité.

Les éléments ne quittent jamais l'origine de ton coffre : le contenu n'est envoyé que vers les champs du formulaire, sur ton ordinateur.
