Sécurité — ce que fait (et ne fait pas) l'extension

Zero-knowledge : le mot de passe maître et la clé ne vivent qu'en mémoire, jamais sur disque.

Aucune interface n'est jamais injectée dans les pages web (pas d'icône dans les champs, pas de bulle) : le remplissage n'agit que sur ton clic dans le popup.

Le coffre déchiffré reste dans le processus d'arrière-plan ; verrouillage auto après inactivité.

Les éléments ne quittent jamais l'origine de ton coffre : le contenu n'est envoyé que vers les champs du formulaire, sur ton ordinateur.
